# 🌈 easy-project

A colorful HTML & CSS learning project that demonstrates how to create interactive visual effects.  
Perfect for beginners who want to explore color transitions, text animations, and image hover effects.

---

## ✨ What You’ll Learn
- Change background and text colors dynamically  
- Apply animated rainbow effects to words  
- Add hover transformations (zoom, rotate) to images  
- Remove image borders for a clean look
